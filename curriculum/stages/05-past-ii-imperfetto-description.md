# Stage 05 — Past II: Imperfetto & Description

**Theme:** imperfetto vs. passato prossimo, physical/personality description.
**Status:** not_started

## Objectives
Add the second past tense and the descriptive vocabulary needed to talk about
what things/people were like, not just what happened.

## Topic checklist
- [ ] Imperfetto formation (regular + irregulars: essere, fare, bere)
- [ ] Imperfetto uses: habitual past, ongoing background action, description
- [ ] Imperfetto vs. passato prossimo — rules of thumb + common trigger words
- [ ] Physical description vocabulary
- [ ] Personality description vocabulary
- [ ] Comparatives (più...di, meno...di, tanto quanto)
- [ ] Superlatives (il più..., -issimo)
- [ ] Mixing both past tenses correctly in one narrative

## Milestone
Describe your childhood and compare it to your life now, unaided, using both
past tenses correctly.

## Definition of done
- All topics taught, checked, and logged.
- Milestone artifact exists in `playground/` or `exercises/solved/`.
- Stage assessment (§10) scored ≥80%.
- Flashcards created for imperfetto conjugations and the two-past-tense contrast rules.
