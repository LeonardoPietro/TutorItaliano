# Stage 01 — Prepositions

**Theme:** Simple prepositions and their articulated (contracted) forms with definite articles.
**Status:** complete

## Objectives
Give the learner a solid, complete handle on the small connector words that
glue almost every Italian sentence together — location, possession,
direction, means — before moving into full present-tense verb conjugation
(Stage 02), where prepositions show up constantly in examples.

## Topic checklist
- [x] Simple prepositions: a, di, da, in, con, su, per, tra/fra
- [x] Articulated prepositions with **a** (al, allo, alla, all', ai, agli, alle)
- [x] Articulated prepositions with **di** (del, dello, della, dell', dei, degli, delle)
- [x] Articulated prepositions with **da** (dal, dallo, dalla, dall', dai, dagli, dalle)
- [x] Articulated prepositions with **in** (nel, nello, nella, nell', nei, negli, nelle)
- [x] Articulated prepositions with **su** (sul, sullo, sulla, sull', sui, sugli, sulle)
- [x] When NOT to articulate (con/per/tra rarely contract; con can optionally: col, coi)
- [x] Common fixed expressions using each preposition (vado a, vengo da, parlo di, sono in, esco con)

## Milestone
Describe the location of 5 objects/places using at least 4 different
articulated prepositions, unaided (e.g., "Il libro è sulla tavola," "Vengo
dall'Italia").

## Definition of done
- All topics taught, checked, and logged.
- Milestone artifact exists in `playground/` or `exercises/solved/`.
- Stage assessment (§10) scored ≥80%.
- Flashcards created for every simple preposition and every articulated form family.
