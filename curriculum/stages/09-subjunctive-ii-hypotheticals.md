# Stage 09 — Subjunctive II & Hypotheticals

**Theme:** congiuntivo imperfetto/passato, periodo ipotetico ("if" sentences).
**Status:** not_started

## Objectives
Close the exact gap the onboarding placement diagnostic exposed: hypothetical
("if I had time, I would...") sentences, which require congiuntivo imperfetto
+ conditional working together.

> **Placement note:** during onboarding the learner attempted this structure
> with "ci io ho tempo, io viaggerò per Italia" — wrong "if" word (used *ci*
> instead of *se*), wrong mood/tense (present+future instead of
> subjunctive+conditional), wrong preposition (*per* instead of *in*). Use
> this exact sentence as a diagnostic touchstone when this stage begins.

## Topic checklist
- [ ] Congiuntivo imperfetto formation
- [ ] Congiuntivo passato and trapassato (recognition-level)
- [ ] Periodo ipotetico della realtà (se + indicativo)
- [ ] Periodo ipotetico della possibilità (se + congiuntivo imperfetto + condizionale presente)
- [ ] Periodo ipotetico dell'irrealtà (se + congiuntivo trapassato + condizionale passato)
- [ ] Common fixed hypothetical expressions
- [ ] Direct correction pass on the onboarding sentence

## Milestone
Correctly build 5 hypothetical sentences spanning all 3 types (real,
possible, unreal), unaided.
