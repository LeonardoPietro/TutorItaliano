# Stage 06 — Pronouns & Connected Speech

**Theme:** Direct/indirect object pronouns, combined pronouns, ne/ci, reflexives.
**Status:** not_started

## Objectives
Stop the learner from sounding like a phrasebook — natural Italian leans
heavily on pronouns to avoid repeating nouns, and this stage builds that
fluency.

## Topic checklist
- [ ] Direct object pronouns (mi, ti, lo, la, ci, vi, li, le)
- [ ] Indirect object pronouns (mi, ti, gli, le, ci, vi, gli/loro)
- [ ] Combined double pronouns (me lo, te la, glielo, ecc.)
- [ ] Reflexive verbs review + reciprocal reflexives
- [ ] Particle **ne**
- [ ] Particle **ci** (locative + idiomatic uses)
- [ ] Pronoun placement with infinitives, modal verbs, and the imperative
- [ ] Past participle agreement with a preceding direct object pronoun

## Milestone
Retell a story from an earlier stage, replacing repeated nouns with the
correct pronouns throughout.

## Definition of done
- All topics taught, checked, and logged.
- Milestone artifact exists in `playground/` or `exercises/solved/`.
- Stage assessment (§10) scored ≥80%.
- Flashcards created for each pronoun set and the combined-pronoun forms.
