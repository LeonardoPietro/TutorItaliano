# Bonus Module — Slang, Vulgar Register & Cultural Swearing

**Status:** optional side track — does NOT count toward `progress/progress.json`
stage mastery or the beginner→expert roadmap. Enter this module only when the
learner explicitly asks for it (e.g. "modulo palavrões", "ensina gírias").

**Theme:** Italian is a language with rich, regionally varied vulgar/informal
vocabulary. This module treats it as a deliberate, labeled cultural-literacy
detour — not something ever slipped into regular grammar practice unlabeled.

## Objectives
- Recognize common Italian curse words/insults and their literal + actual meaning.
- Understand grammatical behavior (most follow the regular -o/-a/-i/-e adjective
  or noun agreement patterns already taught in Stage 02 — swearing doesn't
  break the grammar, just the register).
- Understand REGISTER: which words are mild ("cavolo") vs. strong, and in what
  contexts (friends vs. formal, regional slurs to avoid entirely).
- Recognize a few common regional variants if relevant (the learner can specify
  a region of interest — Roman, Milanese, Neapolitan slang differ).

## Topic checklist
- [ ] Mild/family-friendly exclamations (cavolo, mannaggia, accidenti) — the
      "safe" tier, usable almost anywhere
- [ ] Common insults and their grammatical gender/number agreement
- [ ] Strong vulgar vocabulary (sexual/scatological) — meaning, register, and
      explicit guidance on when NOT to use them
- [ ] Slurs and genuinely offensive terms — flagged as off-limits, not taught
      as usable vocabulary, only named so the learner recognizes and avoids them
- [ ] Regional variation (learner picks a region if interested)

## Milestone
None — this is a recognition/cultural-literacy module, not a production skill
tracked toward fluency. No quiz gate, no mastery percentage.
