# Stage 02 — Present-Tense Basics

**Theme:** Regular verb families + core irregulars, adjectives, questions.
**Status:** not_started

## Objectives
Move from naming things (Stage 00) to describing actions and states in the
present — the tense that carries most everyday conversation.

## Topic checklist
- [ ] Regular **-are** verbs, present tense
- [ ] Regular **-ere** verbs, present tense
- [ ] Regular **-ire** verbs, present tense (plain + **-isc-** pattern)
- [ ] Core irregulars: andare, fare, potere, volere, dovere, venire
- [ ] Adjective agreement (gender/number) and placement (before/after noun)
- [ ] Possessive adjectives (mio, tuo, suo, nostro, vostro, loro)
- [ ] Negation with **non**
- [ ] Yes/no questions and wh-questions in present tense
- [ ] Days of the week, months, telling time

## Milestone
Describe your daily routine in 8+ correct present-tense sentences, unaided.

## Definition of done
- All topics taught, checked, and logged.
- Milestone artifact exists in `playground/` or `exercises/solved/`.
- Stage assessment (§10) scored ≥80%.
- Flashcards created for verb endings, irregulars, and possessives.
