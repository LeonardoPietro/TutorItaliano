# Stage 02 — Present-Tense Basics

**Theme:** Regular verb families + core irregulars, adjectives, questions.
**Status:** complete (9/9 — fechado na Sessão 23, 2026-07-31; ver ressalva de avaliação no ERRATA de 2026-08-04)

## Objectives
Move from naming things (Stage 00) to describing actions and states in the
present — the tense that carries most everyday conversation.

## Topic checklist
- [x] Regular **-are** verbs, present tense
- [x] Regular **-ere** verbs, present tense
- [x] Regular **-ire** verbs, present tense (plain + **-isc-** pattern)
- [x] Core irregulars: andare, fare, potere, volere, dovere, venire
- [x] Adjective agreement (gender/number) and placement (before/after noun)
- [x] Possessive adjectives (mio, tuo, suo, nostro, vostro, loro)
- [x] Negation with **non**
- [x] Yes/no questions and wh-questions in present tense
- [x] Days of the week, months, telling time

## Milestone
Describe your daily routine in 8+ correct present-tense sentences, unaided.
