# Stage 08 — Subjunctive I

**Theme:** congiuntivo presente, opinions/doubts/wishes, common triggers.
**Status:** not_started

## Objectives
Introduce the mood Italians use constantly for opinion, doubt, and desire —
the biggest single jump in sounding natural rather than textbook-literal.

## Topic checklist
- [ ] Congiuntivo presente formation (regular + common irregulars: essere, avere, andare, fare)
- [ ] Indicative vs. subjunctive: when a "che" clause requires it
- [ ] Trigger verbs of opinion (penso che, credo che)
- [ ] Trigger verbs of doubt/uncertainty (dubito che, non sono sicuro che)
- [ ] Trigger verbs of wish/desire (voglio che, spero che)
- [ ] Impersonal expressions (è possibile che, è importante che)
- [ ] Subjunctive vs. infinitive shortcut (same-subject sentences)

## Milestone
Give 5 genuine opinions in Italian, each correctly using a different
subjunctive trigger.

## Definition of done
- All topics taught, checked, and logged.
- Milestone artifact exists in `playground/` or `exercises/solved/`.
- Stage assessment (§10) scored ≥80%.
- Flashcards created for each trigger category and irregular subjunctive forms.
